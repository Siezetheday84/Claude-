## Что видно оператору и другим приложениям

### Оператор (МТС, Мегафон, Билайн, Теле2)

| Что видит оператор | Ответ |
|---|---|
| Протокол | HTTPS (TLS 1.3) — неотличимо от браузера |
| Целевой домен | `microsoft.com` (SNI) |
| Факт VPN | **Нет** — REALITY скрывает тип трафика |

### Другие приложения на iPhone/iPad

**Да, видят факт VPN.** На iOS, как и на Android, полный тоннель создаётся через `NEVPNManager` / `NETunnelProviderManager` (Network Extension). iOS отображает значок VPN (буква **VPN**) в статус-баре.

Приложения могут проверить наличие VPN через `NWPathMonitor` или `SCNetworkReachability` — это системный API, обойти без jailbreak невозможно.

**Практически:** большинство российских банковских приложений на iOS VPN-проверку не делают так агрессивно, как на Android. Но если приложение отказывает — добавьте его в split-tunnel исключения.

## Hiddify Next — полная настройка (рекомендуется)

Hiddify Next использует sing-box с TUN-режимом — весь трафик iPhone проходит через VPN.

### Шаг 1: Импорт

1. Скопируйте `vless://...` из `clients/client.uri`
2. Hiddify Next → **+** → **Добавить по ссылке** → вставьте
3. **Подключиться** → iOS запросит разрешение на создание VPN-конфигурации → **Разрешить**

### Шаг 2: Проверить TUN-режим

Настройки Hiddify → **Режим туннеля: Полный (TUN)**

### Шаг 3: Kill-switch на iOS

iOS не предоставляет системного kill-switch как Android. Варианты:
- Hiddify → **Настройки → Kill Switch: Вкл** (блокирует трафик при обрыве VPN)
- Системный VPN с `Always-on` доступен только через MDM-профиль (корпоративные устройства)

### Шаг 4 (опционально): Исключить приложения

Hiddify → **Раздельное туннелирование** → добавьте банковские приложения в **Bypass** (прямой трафик).

## Streisand — полная настройка

1. Streisand → **Серверы** → **+** → **Вставить из буфера** → вставьте VLESS URI
2. Streisand автоматически настроит REALITY-соединение
3. Нажмите **Подключиться** — iOS запросит разрешение
4. Streisand → **Настройки** → **Режим: Полный туннель**

## Использование singbox-tun-full.json

Если используете sing-box напрямую — возьмите `clients/singbox-tun-full.json`:

- TUN-интерфейс (весь трафик через VPN)  
- DNS-over-TLS через туннель (нет DNS-утечек к российским DNS)  
- Kill-switch (`strict_route: true`)  

Импорт: скопируйте файл на телефон → откройте в sing-box → **Import**.

---

## Проверка после подключения

- `https://whoer.net` — IP должен быть VPS, страна — не Россия
- `https://dnsleaktest.com` — DNS-серверы вне России (Cloudflare 1.1.1.1)
- Telegram открывается без прокси внутри приложения

## Telegram: порядок запуска

Запускайте VPN **до** открытия Telegram. Если Telegram уже был запущен без VPN — полностью закройте его (смахните из App Switcher) и откройте заново после подключения VPN.
