# Android-клиент — Hiddify Next / v2rayNG

---

## Что видно оператору и другим приложениям

### Оператор мобильной связи (МТС, Мегафон, Билайн, Теле2)

| Что видит оператор | Ответ |
|---|---|
| Протокол | HTTPS (TLS 1.3) — неотличимо от браузера |
| Целевой домен | `microsoft.com` (SNI в handshake) |
| IP назначения | IP вашего VPS |
| Содержимое | Нет — зашифровано |
| Факт VPN | **Нет** — REALITY делает трафик неотличимым от обычного HTTPS |

**Оговорка:** оператор видит, что весь трафик идёт на один IP. Это поведенческая аномалия, но не DPI-обнаружение. ТСПУ работает через DPI — и именно от него REALITY защищает.

### Другие приложения на телефоне (Сбербанк, Тинькофф и т.д.)

**Да, видят.** Это ограничение Android, не протокола.

Любой полный тоннель (TUN-интерфейс) на Android создаётся через `VpnService`. Android:
- Показывает значок ключа в статус-баре
- Регистрирует VPN-соединение в `ConnectivityManager`
- Приложения могут вызвать `network.getCapabilities().hasTransport(TRANSPORT_VPN)`

Банковские приложения используют эту проверку и могут отказать в работе. Обойти без root невозможно — это системный механизм ОС.

**Решение:** переключитесь в браузер для банков, когда VPN активен. Или добавьте приложения банков в исключения (split tunnel — см. ниже).

## Hiddify Next — полная настройка (рекомендуется)

Hiddify Next использует sing-box внутри и по умолчанию создаёт TUN-тоннель — весь трафик телефона идёт через VPN.

### Шаг 1: Импорт сервера

1. Скопируйте содержимое `clients/client.uri` (строка `vless://...`)
2. Откройте Hiddify Next → **+** → **Добавить по ссылке** → вставьте URI
3. Нажмите **Подключиться**

### Шаг 2: Убедитесь что включён TUN-режим

Hiddify Next → Настройки → **Режим туннеля: VPN (TUN)**

В этом режиме **весь трафик телефона** — включая Telegram — проходит через VPN.

### Шаг 3 (опционально): Добавить исключения для банков

Hiddify Next → Настройки → **Обход приложений** → добавьте Сбербанк, Тинькофф и т.д.  
Трафик этих приложений пойдёт напрямую, минуя VPN.

### Шаг 4: Kill-switch

Hiddify Next → Настройки → **Kill Switch: Включён**  
При обрыве VPN трафик блокируется полностью (Telegram не "вытечет" в незащищённую сеть).

## v2rayNG — полная настройка

### Импорт

1. В v2rayNG: **+** → **Импортировать из буфера обмена** → вставьте `vless://...`
2. Или: **+** → **Сканировать QR** → отсканируйте `qr-code.png`

### Обязательно: включить VPN Mode (TUN-тоннель)

По умолчанию v2rayNG работает как локальный SOCKS5-прокси — Telegram через него **не пойдёт**.

Чтобы весь трафик шёл через VPN:

- В главном окне v2rayNG включите переключатель — он запросит создание VPN-соединения → разрешите
- Или: **Настройки** → **VPN Mode** → включить

### Always-On VPN (защита от утечки при перезагрузке)

```
Настройки телефона → Сеть → VPN → v2rayNG → ⚙ → Всегда включён VPN: ON
                                                  → Блокировать соединения без VPN: ON
```

Второй параметр — это kill-switch: при обрыве VPN весь трафик блокируется.

## Использование singbox-tun-full.json (продвинутый вариант)

Если используете sing-box напрямую или NekoBox, возьмите файл `clients/singbox-tun-full.json` — это полный конфиг с:
- TUN-интерфейсом (весь трафик через VPN)
- DNS-over-TLS через туннель (нет DNS-утечек)
- Kill-switch (`strict_route: true`)
- Блокировка рекламы на уровне DNS

Импорт в NekoBox: **Группы** → **Добавить** → **Импорт конфига** → выберите `singbox-tun-full.json`

## Проверка после подключения

- `https://whoer.net` — IP должен быть вашим VPS, страна — не Россия
- `https://web.telegram.org` — должен открываться
- DNS leak test: `https://dnsleaktest.com` — все серверы должны быть вне России

---

## Telegram: запустить после VPN

Telegram должен стартовать **после** того, как VPN поднят. Иначе соединение установится напрямую и Telegram будет работать в обход VPN до следующего перезапуска приложения.

С Always-On VPN этот сценарий исключён: телефон не выпустит трафик без VPN.
