# AI Video Chatbot Service

Сервис создания актуальных видеороликов — привязанных к новостям, трендам и событиям. Управление через Telegram-бот.

## Возможности

- Онбординг клиентов (договор или подписка)
- Настройка профиля (отрасли, регион)
- Еженедельная рассылка 10 актуальных тем по понедельникам
- Генерация сценариев через Claude AI
- Загрузка референсов, логотипов, дисклеймеров
- Отслеживание производства (48 часов)
- Доставка ролика прямо в чат
- 1 раунд правок
- Принятие ролика и переход к следующему
- Подключение аккаунт-менеджера по запросу
- Автоматическое завершение периода и выставление акта

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Создать файл окружения
cp .env.example .env
# Заполнить BOT_TOKEN и ANTHROPIC_API_KEY в .env

# 3. Запустить бота
python bot.py
```

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота (от @BotFather) |
| `ANTHROPIC_API_KEY` | API-ключ Anthropic (Claude) |
| `ADMIN_IDS` | Telegram ID администраторов через запятую |
| `DATABASE_URL` | URL базы данных (по умолчанию SQLite) |
| `TIMEZONE` | Часовой пояс (по умолчанию Europe/Moscow) |

## Структура проекта

```
bot.py              — точка входа
config.py           — конфигурация
database.py         — модели БД и операции
scheduler.py        — планировщик еженедельных задач
states.py           — FSM-состояния
handlers/
  start.py          — онбординг, /start
  account.py        — настройка профиля
  weekly.py         — еженедельный цикл производства
  support.py        — подключение менеджера
  admin.py          — панель администратора
  topic_router.py   — маршрутизация состояний
utils/
  ai.py             — генерация тем и сценариев (Claude)
  keyboards.py      — клавиатуры Telegram
```

## Еженедельный цикл

```
Понедельник 11:00  → 10 тем клиенту
Вторник 10:00      → дедлайн выбора темы
После выбора       → генерация сценария (Claude)
После согласования → загрузка материалов
После загрузки     → 48 часов производства
Готово             → ролик в чат + кнопки правок/принятия
```

## Команды администратора

| Команда | Действие |
|---|---|
| `/admin` | Панель управления |
| `/clients` | Список клиентов |
| `/activate <id>` | Активировать клиента |
| `/send_topics` | Разослать темы вручную |
| `/send_video <id>` | Отправить ролик клиенту |
| `/send_act <id>` | Выслать акт выполненных работ |
| `/broadcast` | Рассылка всем активным |
| `/reply_<id> <текст>` | Ответить конкретному клиенту |

## Команды клиента

| Команда | Действие |
|---|---|
| `/start` | Начать / онбординг |
| `/status` | Статус текущего ролика |
| `/settings` | Изменить отрасли/регион |
| `/support` | Подключить менеджера |
| `подключить аккаунта` | Подключить менеджера (текстом) |
